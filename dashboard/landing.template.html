How it's built

Salesforce data to Process Intelligence in four steps

  1. ExtractSOQL over the REST API for Lead, Opportunity, OpportunityHistory and Task, signed by the Salesforce CLI session. extract.py
  2. CorrelateOne case per deal: Opportunity Id. Tasks join on WhatId, leads on ConvertedOpportunityId. transform.py
  3. LoadCSV and IEEE XES with activity, timestamps, resource and case attributes, ready to import into a process mining tool.
  4. Mine and sizeDirectly-follows graph, variants, cohort win rates and a driver-based value model. mine.py
